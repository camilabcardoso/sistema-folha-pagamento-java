# Sistema de Folha de Pagamento em Java

Projeto desenvolvido para a atividade A3 da unidade curricular de Algoritmos e Programação em Java.

## Descrição

O sistema realiza o cadastro de funcionários e calcula automaticamente a folha de pagamento de acordo com o tipo de colaborador.

O programa possui três categorias de funcionários:

- Funcionário padrão
- Funcionário comissionado
- Funcionário de produção

Os dados são armazenados utilizando ArrayList e o sistema utiliza conceitos de Programação Orientada a Objetos (POO), como herança e polimorfismo.

---

## Funcionalidades

- Cadastro de funcionários
- Cálculo automático de salários
- Menu interativo
- Validação de dados
- Exibição da folha de pagamento
- Estruturas de repetição e decisão

---

## Como executar

1. Abra o projeto em uma IDE Java
2. Execute a classe `A3`
3. Escolha uma opção no menu
4. Cadastre funcionários
5. Gere a folha de pagamento
